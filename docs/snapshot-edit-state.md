# 快照录入的编辑基准

- 金额 Δ 与「只看变化」对比结转原值；「未保存改动」只对比初始化完成或最近成功保存的编辑态，不能用金额变化行数冒充未保存项数。
- 新期先结转，再等待自动汇率成功或明确失败，期间保持加载态；完成后建立干净基准。已有期保留已存汇率。首次进入与切换日期走同一流程，初始化不写本地草稿。
- 行金额、美元输入、币种及美元标记、备注、额度、增删计入未保存行；汇率、期级备注、地点及定位元数据、状态、日期独立标为表单改动。
- 整期保存只推进提交时捕获的编辑态，等待期间的新输入仍未保存；额度窄保存只推进目标行额度基准，不覆盖之后的新输入。失败不得推进基准，旧期回包不得修改新期编辑态。
- 行还原和全部还原恢复保存基准中的美元、备注、额度和完整地点信息；待完成的汇率回包不得覆盖之后的手工输入、切期或还原。显式刷新汇率属于编辑，不属于初始化。
- 前端 `npm test` 使用合成数据、真实 Vue 响应式及录入页脚本验证初始化、日期切换、刷新、计数、还原、保存及异步竞争。测试不得连接线上数据库或保存真实快照。
